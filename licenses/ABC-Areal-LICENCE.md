## What this site does with the fonts

- `public/index.html` inlines two WOFF2 files as base64 `@font-face` sources, self-hosted on
  70347.moldandyeast.com only.
- Each file is a glyph subset of the foundry's variable WOFF2, reduced to printable ASCII plus the other
  codepoints the page uses. WOFF2 in, WOFF2 out: no format conversion, no outline changes; the variation
  axes, layout features and name tables are kept.
- ABC Areal has no ↔ ⌘ ✓ ✗ glyphs, so those characters fall back to the system font.
- The font files are not offered for download and are not committed separately to this repository.
